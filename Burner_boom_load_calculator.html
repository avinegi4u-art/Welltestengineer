Cantilever boom structural check for well-test burner/flare booms rigged to a rig structure or turntable — bending, wind, base reactions, D/t & buckling screening, and proof-load sign-off.

⚠️
Engineering basis & limitations. This tool uses simplified cantilever beam theory (API/ASME-style allowable-stress approach) for a preliminary, first-pass structural check only. It does not replace a full FEA (ANSYS/Abaqus/SACS/etc.), does not account for local stress concentrations, fatigue, corrosion allowance, or non-uniform/tapered sections, and the bolt-group and turntable checks use a simplified rigid-flange approximation. Any burner boom load test, rig-up on a live rig structure, or personnel-safety-critical lift must be reviewed and stamped by a qualified/chartered structural engineer and follow your company's and the rig owner's HSE and lifting procedures before use.

1. Purpose & scope

This calculator performs a first-pass structural screening of a cantilever burner or flare boom rigged to a rig structure or turntable. Version 3 adds a matrix envelope mode inspired by SESAM offshore load-combination reports (e.g. the project 90 ft PDF). It evaluates:

  • Gravity loads (self-weight, fittings, tip equipment) with dynamic amplification
  • Wind load on a circular pipe (ASCE 7 / EN 1991-1-4 style)
  • Combined bending, axial, and shear stress (von Mises-style equivalent stress)
  • Base reactions vs turntable rated moment and load
  • Simplified bolt/pin group tension
  • D/t slenderness and Euler buckling screening
  • Deflection vs a user-set serviceability limit (L/n)
  • Matrix mode: 8 operating/survival/accidental/lifting combinations with 3-direction scale factors; multi-support reactions (kingpost, wind stay, boom rest); windward guyline tension screening
  • Proof-load test evaluation and printable certificate
Important: This tool does not replace finite-element analysis (FEA), certified lift plans, or review by a qualified structural engineer. Use it for planning, preliminary checks, and field documentation only — not as sole approval for rig-up or personnel-under-load operations.

Default configuration: 60 ft boom (18.288 m), NPS 8″ Sch 40 pipe, operating load case (horizontal). A separate 90 ft reference preset is available in the toolbar.

2. Getting started

  1. Download or copy Burner_boom_load_calculator.html to your computer.
  2. Open it in a modern browser (Chrome, Edge, Firefox, Safari). Double-click the file or drag it into a browser window.
  3. No internet connection is required after the file is saved locally.
  4. Your last session is restored automatically from browser localStorage unless you click Reset.
Tip: Bookmark the file path or keep calculator + manual in the same folder. Use Export JSON before clearing browser data or switching machines.

5. Matrix envelope mode (v3)

Matrix mode runs eight fixed combinations aligned with typical offshore burner-boom reports:

GroupCombinationsActive supports
OperatingHeave+Roll, Heave+Pitch, Heave+ResultantTurntable, kingpost, wind stay, guylines
SurvivalHeave+Roll, Heave+Pitch, Heave+ResultantTurntable, boom rest (stowed)
AccidentalStatic heel (dry pipe fraction)Turntable, kingpost
LiftingCrane / guylines (2× weight default)Lifting reduction on base moment

Each combination applies 3-direction scale factors (X lateral ⊥ boom, Y axial ∥ boom, Z vertical) plus directional wind multipliers. This is a screening envelope, not a 3D space-frame FEA — member-by-member checks, temperature derating, and full guyline truss geometry are not modeled.

The Load combination matrix table on Tab 4 lists all rows; the ★ governing row sets the header status pill and the detailed reaction block on Tab 3.

6. Frame solver (v4)

Frame solver + matrix (2D FEA) is the default analysis mode. It builds a 2D plane-frame model in the boom elevation plane:

  • 12 Euler-Bernoulli beam segments along the boom chord (same pipe A, I, E as Tab 1)
  • Truss links for wind stay and windward guylines to fixed deck anchors
  • Support constraints — pinned turntable base; vertical restraints at kingpost / boom-rest nodes per combination
  • Direct stiffness solution — Gaussian elimination on free DOFs; reactions and guy tensions from solved displacements

The same 8 load combinations and 3-direction scale factors apply. Results feed the matrix table and PASS/FAIL checks. This is substantially closer to SESAM-style boundary conditions than 1D screening, but is still a lumped 2D model — not the full 3D braced space frame with box sections, fishplates, and member unity checks from the PDF.

Use Matrix envelope (1D screening) for fast hand-checks; use Frame solver when supports and guylines must interact through stiffness in 2D.

7. 3D space frame (v5) — 60 ft design

3D space frame (PDF topology) is the default mode. It builds a braced space frame for the standard 60 ft (18.288 m) burner boom, with member layout and sections scaled from the CT-12-4536 / SESAM 90 ft report:

  • Coordinates: +X ⊥ boom, +Y along boom, +Z up (PDF §2.1)
  • 18 bays at 1.016 m (60 ft / 18) · four corner chords (box_75 / box_90)
  • Bm119 — top starboard chord segments (box_90x90x8, A=2624 mm²)
  • Bracing: vertical box_75, diagonal L75x75x8, cross L_200x100x10
  • Rope trusses: Sp3 wind stay, Sp4 kingpost guys (56/40 mm), Sp8 lateral guy; Sp5–Sp10 added when effective guylines ≥ 2 (windward screening count on Tab 3)
  • Supports: deck anchors fixed at connected Sp nodes; kingpost / wind-stay / guy positions follow rig preset or custom Tab 3 values
  • Accidental heel: dry-pipe fraction varies base→tip; static heel angle tilts weight in 3D accidental combination
  • Member table: Bm119 chords, all guy ropes, and bracing (D/V/X) unity — top 25 by utilization
  • Rig presets: toolbar Rig dropdown + Save rig stores support positions in browser localStorage

Use the toolbar 90 ft reference preset only when comparing against the original SESAM PDF. The default 60 ft case is the operational burner boom configuration.

8. Understanding PASS / MARGINAL / FAIL

PASS — primary checks OK
Stress SF, turntable moment/load, bolt utilization, buckling, and (matrix mode) kingpost / wind stay / boom rest / guyline checks are within limits for the governing combination.
MARGINAL — deflection
Strength is OK but tip deflection exceeds L/n serviceability criterion. Review with engineer; may still be acceptable per operator spec.
FAIL — strength/capacity
One or more primary checks exceeded: stress, turntable, bolts, buckling, multi-support capacity, guyline tension, or invalid geometry.

On Tab 4, individual result tiles use green / amber / red borders. The banner distinguishes primary strength failures from serviceability deflection warnings.

9. Tab 3 — Rig / Turntable Interface

Enter rated capacities from rig or equipment documentation:

  • Turntable rated moment — maximum bending moment at base connection (kN·m or kip·ft).
  • Turntable rated load — combined reaction capacity (kN or kip).

Bolt / pin group (simplified rigid-flange model):

  • Bolt circle diameter (BCD), number of bolts N, allowable tension per bolt.
  • Max bolt tension ≈ 2M/(NR) + N_axial/N — first-pass screening only.

Multi-support boundary conditions (matrix mode)

Enable/disable supports and enter position + rated capacity. The tool computes simplified static reactions and reduces turntable moment when a vertical support (kingpost or boom rest) carries part of the vertical load. Wind stay carries lateral load before guyline tension is calculated.

  • Kingpost — vertical support, active in operating and accidental combinations.
  • Wind stay — lateral support at boom, operating combinations only.
  • Boom rest — vertical support when boom is stowed, survival combinations.
  • Accidental dry factor — fraction of operating weight for empty-pipe accidental case (default 0.85).
  • Lifting load factor — multiplier on total weight for lifting combination (default 2.0).

Guyline screening

Windward effective guylines share residual lateral load after wind-stay capacity. Tension T ≈ (F_x / n_guys) / sin(angle). Compare to allowable per guy. Guy length is recorded for documentation; tension uses angle and lateral force only (straight-line screening).

The Base reaction summary table updates with moment, shear, axial force, buckling check, bolt utilization, and (matrix mode) multi-support and 3-direction force components for the governing combination.

10. Tab 4 — Results

Load combination matrix (matrix mode)

Eight rows with stress utilization, safety factor, base moment, guyline tension, and pass/fail. The governing row (★) drives the sticky header status and governs charts/schematic values.

Quality checks

Validates geometry (positive dimensions, t < OD/2, D/t warning, load position within span).

Structural summary tiles

  • Equivalent stress σ_eq — combined bending + axial + shear (von Mises-style).
  • Actual safety factor — Fy / σ_eq vs target SF.
  • Buckling SF — Euler capacity with K=2 (cantilever) vs axial component.
  • Deflection — resultant gravity + wind deflection vs L/n.
  • Bolt utilization — percentage of allowable per-bolt tension.

Schematic & charts

The boom schematic shows angle, length, and key reactions (not to scale). Charts plot bending moment and deflection from base to tip.

Full calculation report

Single table suitable for copy/paste into a calculation sheet or email. All values respect the selected unit system.

11. Tab 5 — Load Test Sign-off

Use after a physical proof load test on the boom:

  1. Set SWL (Safe Working Load) — total rigged payload reference (kg or lb).
  2. Set test load factor — typically 1.5× SWL.
  3. Review predicted deflection from beam theory (static, no DAF/wind).
  4. Enter measured deflection under test load and permanent set after unload.
  5. Confirm visual inspection checkbox — no cracks, weld defects, or permanent distortion.
  6. Complete certificate fields: Asset ID, rig/location, date, tested by, witnessed by.

Acceptance criteria

  • Permanent set ≤ configured % of measured deflection (default 10%).
  • Visual inspection confirmed.
  • Measured deflection compared to prediction within ±35% informational band (warning if outside — investigate, not automatic fail).

Click Print / Save Certificate as PDF to generate a sign-off sheet with signature lines for tester, witness, certifying engineer, and client representative.

14. Limitations & standards

Simplified models referenced in the calculator footer:

  • AISC ASD allowable stress (Fy / SF)
  • API 5L / ASTM pipe grades
  • ASCE 7-16 velocity pressure (via ½ρV² with exposure factor)
  • EN 1991-1-4 wind on cylinders (Cd)
  • Euler column buckling (K = 2 cantilever)
  • Matrix envelope scale factors — screening defaults inspired by SESAM reports, not ship-specific RAO calibration

Not modeled: fishplate clusters, fatigue, corrosion allowance, tapered sections, full SESAM member inventory (~450 members), ship-specific RAO calibration, dynamic wind time history, or lift-plan rigging angles. The 3D space frame is a reduced braced model — chord bending uses tributary distribution from solved base reactions; axial and rope forces use the stiffness solution.

Modeled (v5): 3D braced space frame (60 ft default), 8-combination matrix envelope, member unity screening, 1.27× frame self-weight, multi-support reactions, export to CSV/JSON.

Reference document in repository: Structural Analysis of 90 Ft Burner Boom (PDF).

15. FAQ & troubleshooting

Simple vs matrix vs 3D?

Simple cantilever — single operating/erection/storm preset. Matrix 1D — 8 combinations, 1D screening. 2D frame — plane-frame stiffness with guys/stays. 3D space frame (default) — 60 ft braced topology with member table. Use Compare modes on Tab 4 to see governing utilization side-by-side.

Why does status show MARGINAL but stress passes?

Long pipe cantilevers often exceed L/200 deflection under self-weight while stress remains acceptable. The tool separates serviceability (MARGINAL) from strength (FAIL).

Values look wrong after switching units

Switch units once and verify inputs. If corrupted, click Reset and re-enter, or Import a known-good JSON.

Old 9 m defaults appear on open

Browser localStorage may hold a previous session. Click Reset or clear site data for the file URL.

Can I use this for official lift approval?

No — only as a screening aid. Official approval requires qualified engineer review, operator procedures, and often independent inspection.

Does it work offline?

Yes. The entire application is a single HTML file with embedded CSS and JavaScript.
