1. Overview and getting started

What this app does

This is a browser-based DST pressure transient analysis (PTA) tool for screening and office review. It helps you:

  • Import gauge and rate data (CSV, paste, manual entry, optional live JSON polling)
  • Auto-detect flow, shut-in, cleanup, restart, and afterflow periods
  • Run Horner and Bourdet derivative interpretation with superposition for variable-rate DSTs
  • Arbitrate models (Horner, derivative, type curve, boundary) with explicit accept/reject reasons
  • Apply calibrated 95% uncertainty envelopes and interpretation gating
  • Screen composite/multilayer behavior and boundary effects
  • Compare pre-acid and post-acid buildups
  • Export text, HTML, PDF, plots, and an engineer-facing CSV table
Screening tool, not a full commercial PTA replacement. Results should be validated by an experienced well-test engineer before external reporting, reserves work, or operational decisions. The app is designed to support Kappa-style office discipline, not replace rigorous commercial software without review.

How to open the app

  1. Open dst-pressure-transient-analysis-pro-v2.7.html in Chrome, Edge, or Firefox.
  2. No installation or server is required.
  3. Data is stored locally in your browser unless you configure endpoint polling.
  4. Click Load DST demo on first use to learn the interface.

3.3 Live endpoint polling (optional)

For a JSON feed from a historian, WITSML bridge, or office proxy:

  1. Enter the JSON endpoint URL
  2. Set poll interval (seconds, minimum 5)
  3. Click Poll once or Start polling

Supported JSON shapes: a single row object, an array of rows, or { "rows": [...] }.

The endpoint must allow browser CORS access, or you must use a same-origin proxy. If polling fails, use CSV import instead.

5.6 Deconvolution (variable-rate DSTs)

For DSTs with rate changes before shut-in, review the deconvolution panel:

  • Raw vs deconvolved log-log comparison
  • Kernel audit — which flow segments materially affect superposition
  • Stability rating: stable / marginal / unstable

If deconvolution is unstable, prefer raw curves or fix rate allocation before trusting Horner or derivative picks.

8. Typical office workflows

8.1 Standard single-buildup DST

Import CSV → Check QC → Correct periods → Set reservoir inputs → Select buildup → Auto fit from derivative → Tune Bourdet L → Review arbitration + gating → Build report → Export

8.2 Acid job (pre/post comparison)

Import data → Add "Acid job" event at acid time → Analyze post-acid buildup (and pre-acid if needed) → Step-rate tab: compare buildups → Check stimulation assessment → Include multi-buildup section in report

8.3 Messy variable-rate DST

Import data → Diagnostics: deconvolution panel → Compare raw vs deconvolved log-log → If unstable: fix rates or justify raw-curve use → Do not approve report until deconv is stable or explained

8.4 Near-boundary well

Diagnostics: review boundary type (sealing vs constant-pressure) → Check "fit before boundary onset" gate → Truncate Horner fit end if contaminated → Use type curve only before boundary uplift → Document boundary distance and influence window

9. Understanding the numbers

Permeability (k)

  • Horner k — from straight-line slope
  • Derivative k — from Bourdet plateau
  • Consensus envelope — overlap of Horner and derivative 95% bands
  • Non-overlapping bands reduce calibration score and tighten gating

Skin (S)

Fit-propagated from Horner. Large |S| may indicate damage, stimulation, multiphase cleanup, or incorrect inputs.

p*

Extrapolated infinite-acting pressure from the Horner intercept. Not necessarily static reservoir pressure if boundaries or composite effects dominate.

PI (productivity index)

q / (p* − pwf) in bpd/psi. Screening value only.

Uncertainty calibration score (0–100)

ScoreGradeRecommended use
≥ 78Well-calibratedReasonable for office report with engineering review
55–77Moderately calibratedUse ranges, not point values
< 55Poorly calibratedScreening only; collect more radial-flow data

11. Limitations and responsible use

  • Single-file browser app — no multi-user database or audit trail beyond exported files
  • Superposition deconvolution is screening-grade, not rigorous commercial deconvolution
  • Boundary and composite logic are rule-based screens, not full reservoir simulation
  • Type curve overlay is WBS + radial only — no full layered inversion
  • Uncertainty bands are calibrated screening envelopes, not full Monte Carlo analysis
  • Always validate gauge calibration, rate allocation, PVT, geology, and phase behavior independently
Use gating labels honestly. “Screening only” is for internal discussion. “Review required” needs senior review before external circulation. “Approved” still requires engineer sign-off and professional judgment.
